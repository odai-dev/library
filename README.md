# Digital Library Catalog App

[![JavaScript](https://img.shields.io/badge/JavaScript-Vanilla%20ES6-F7DF1E?style=for-the-badge&logo=javascript)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)

An interactive digital bookshelf and book catalog application built with vanilla JavaScript. Demonstrates object constructor patterns, prototype inheritance, and dynamic DOM manipulation.

---

## 🌟 Key Features
- **Book Object Modeling**: Custom `Book` prototypes with title, author, page count, and read status.
- **Dynamic Catalog Grid**: Add new books via interactive modal dialog and render card representations instantly.
- **Read Status Toggle**: Toggle between "Read" and "Not Read Yet" on any card with persistent state updating.
- **Catalog Deletion**: Remove individual books from the library collection.
